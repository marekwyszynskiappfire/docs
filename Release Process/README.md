# Release Process

Workspace for the **BigPicture Release Process** after the Cloud/DC split and the
QA/Release re-organisation at the end of August 2026.

The [PPM Release Checklist](https://appfire.atlassian.net/wiki/spaces/PROC/pages/277840434/PPM+Release+Checklist)
is the technical source of record. It is not the process description, and it
does not define current ownership.

## Contents

- [`SKILL.md`](SKILL.md) — agent workflow for this project.
- [`process.md`](process.md) — succinct process draft (review this first).
- [`technical/cloud.md`](technical/cloud.md) — Cloud (and Monday) how-tos.
- [`technical/dc.md`](technical/dc.md) — Data Center how-tos.
- [`config/project.json`](config/project.json) — metadata and source links.
- [`artifacts/`](artifacts/) — local notes (gitignored dumps).
