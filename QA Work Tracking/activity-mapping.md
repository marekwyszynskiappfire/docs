# QA activities → Jira mapping

From [qa_work_tracking_in_jira.md](../../../QA_TRANSPARENCY/qa_work_tracking_in_jira.md).

**App QA Project** = QA Jira project per product (engineer provides key, e.g. `TC`).

| Task | Issue type | Jira project | Team | Metric |
| --- | --- | --- | --- | --- |
| Test Run | Test Execution & linked Task per QA involved | App QA Project | Horizon | feature / maintenance |
| Sanity | Test Execution | App QA Project | Horizon | feature / maintenance |
| PR Testing | Test Execution | App QA Project | Eng team | feature |
| Exploration tests | Test Execution | App QA Project | Eng team | feature |
| Bugs Reproduction | Task | App QA Project | Eng team | maintenance |
| Bugs retesting | Test Execution | App QA Project | Eng team | maintenance |
| New TC creation | Task & Test Case | App QA Project | Eng team | feature |
| New TC Automation | Test Case | App QA Project | Eng team | feature |
| Updating TC (manual) | Task | App QA Project | Eng team | maintenance |
| Updating TC (auto) | Task | App QA Project | Eng team | maintenance |
| Support | Task | App QA Project | Eng team | l3 support |
| Analyses (requirements, metrics, TC cleanup) | Task | App QA Project | Horizon | feature / maintenance |
| Documentation | Task | App QA Project | Horizon | per case |
| Training | Task | QA CoE project | Horizon | — |

For **five work types** (product, maintenance, release, automation, operational excellence) and Epic/link rules, see [work-model.md](work-model.md).
