# Reviewer portfolio report (Profile B template)

Static shell for multi-Epic Reviewer runs. **Do not edit copies under a run folder** — change this template, then re-run `build_portfolio_report.py`.

Generated per run: `{portfolio_run_dir}/portfolio/` with `data/report-data.js` and copied epic reports under `epics/{KEY}/`.

See [`../../shared/html-report-guidelines.md`](../../shared/html-report-guidelines.md) and `The Reviewer/SKILL.md` (portfolio bundle).
