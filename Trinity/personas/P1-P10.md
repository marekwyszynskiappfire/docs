## P1–P10 — role, need, Trinity touchpoint

| ID | Role | Primary need | Where Trinity serves it today |
|----|------|--------------|-------------------------------|
| **P1** | QA engineer | Triage, edit tests, trace to AC, clear data | Reviewer run + Studio unit review; Creator run (edit, approve/reject); coverage matrix on Creator run |
| **P2** | QA lead / manager | Coverage, tiers, effort, release picture | Reviewer Tier 1 + portfolio; Creator summary + **coverage panel** + Profile B **suite-report**; [`METRICS.md`](../METRICS.md) |
| **P3** | PM / BA | Assumptions visible; answer questions; plain language | Reviewer readiness + Q#; Reviewer gate ack on Importer plan (PM-safe summary) |
| **P4** | Automation engineer | Candidates, stability, handoff metadata | Creator `automation_fit`, `automation_blockers`, `automation_candidate`; Importer export subset |
| **P5** | Skill maintainer | One contract, versioned rules | `reviewer/checklist.md`, schemas, `personas/*.md`, [`PORT-CHECKLIST`](../creator/PORT-CHECKLIST.md), ADRs under `docs/adr/` |
| **P6** | Test-data steward | Isolation, parallel workers, no invented users | Creator `test_data_prerequisites` / preconditions; product config — not Reviewer |
| **P7** | UX designer | Design-linked expectations from review | Reviewer findings with `owner_hint: UX`; Creator cites `source_quotes` — no duplicate Figma fetch |
| **P8** | Release / delivery manager | Epic rollout, child inventory, batch status | Reviewer Epic mode + portfolio Profile B; Studio pipeline run + Creator handoff JQL |
| **P9** | Security / compliance | No secrets/PII in shared artifacts | Reviewer `data_sensitivity`; Importer **export preflight** redaction warnings |
| **P10** | Platform / MCP admin | Visible source load failures | Reviewer `context_loaded[]` in payload/HTML (**Data sources** section) |
