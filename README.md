# DOCS repository

This repo holds **Trinity** (AI-assisted QA pipeline: Reviewer, Creator, Importer, Trinity Studio) and **agent/GitHub documentation** under `docs/` (ADRs, issue tracker, domain layout).

Older team material (releases, 1:1 templates, BP QA, `AI in QA/`, etc.) lives in **`archive/`** on your machine only — that folder is gitignored and is not pushed to GitHub. Pre-Trinity skill trees (`The Reviewer/`, `The Creator/`, `TestCaseCreator/`, root `Creator/`) were removed; use **`Trinity/reviewer`** and **`Trinity/creator`** only.
