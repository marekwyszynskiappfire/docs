**Release Process:** [`Release Process/`](Release%20Process/README.md) — succinct process draft plus Cloud and DC technical runbooks; Confluence after persona review.

Older team material (1:1 templates, `AI in QA/`, leftover local copies, etc.) lives in **`archive/`** on your machine only — that folder is gitignored and is not pushed to GitHub. Pre-Trinity skill trees (`The Reviewer/`, `The Creator/`, `TestCaseCreator/`, root `Creator/`) were removed; use **`Trinity/reviewer`** and **`Trinity/creator`** only.
